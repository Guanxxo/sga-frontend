# Conclusiones - Tarea Final

El desarrollo del frontend del Sistema de Gestión Académica (SGA) mediante React 
y Vite permitió consolidar los conocimientos adquiridos durante el ciclo académico. 
La integración con el backend FastAPI desarrollado en la Tarea T02.03 demostró la 
importancia de diseñar APIs REST bien documentadas, ya que facilitó enormemente 
el consumo de servicios desde el frontend.

El uso de React como framework frontend permitió crear una interfaz de usuario 
modular y reutilizable, organizando el código en componentes independientes como 
Navbar, Footer, Alerta, Boton y Tarjeta. Esta arquitectura basada en componentes 
facilita el mantenimiento y la escalabilidad del sistema.

La librería Axios simplificó el proceso de comunicación HTTP con el backend, 
permitiendo realizar operaciones CRUD completas desde la interfaz gráfica. La 
configuración de CORS en FastAPI fue fundamental para permitir la comunicación 
entre el frontend en el puerto 5173 y el backend en el puerto 8000.

El Dashboard con estadísticas en tiempo real demostró cómo un frontend bien 
diseñado puede proporcionar información valiosa de manera visual e intuitiva. 
La implementación del flujo completo de matrículas con sus diferentes estados 
evidenció la complejidad de los sistemas académicos reales.

En conclusión, este proyecto integró exitosamente las fases de análisis, diseño, 
implementación backend, pruebas unitarias y desarrollo frontend, completando el 
ciclo completo de desarrollo de software.
